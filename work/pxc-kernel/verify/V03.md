Findings the pictures produced that the tests had not:

- The cache serves a world.drive from entries a nested ctx.drive made, because both are keyed by implementation, input and tick. This is now asserted in the facts file.
- A view heuristic ("a label with no spaces is a step name") was guessing at something the kernel knew. The kernel now records `ran`/`skipped` on composition decisions.
