The Part (the standard every implementation must fit)

Card pixel bounds: the smallest rectangle holding every pixel of a card raster whose alpha is above 0. Units: canvas pixels. Frame: the card's own canvas, origin top left. Shape: { x, y, w, h }, half-open, so the right edge is x + w and the pixel at x + w is outside. A raster with no visible pixel has no bounds (null).
